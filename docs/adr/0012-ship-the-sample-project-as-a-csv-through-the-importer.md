# Ship the Sample Project as a CSV through the importer

New users need something to explore before they have an Event Log of their own, and the Tours that teach each view need data with a known finding to point at. The app therefore ships a Sample Project: a synthetic loan application log whose story is fixed. Rejected applications loop through "Request documents", arrive through a broker more often and ask for larger amounts, some are rejected right after the completeness check, and region makes no difference at all.

The log is a CSV bundled as a Tauri resource, `resources/sample-project/loan-applications.csv`. The `create_sample_project` command resolves it and hands it to `import_event_log` with the Groups to apply, the same call `seed-project` makes (ADR 0008). Shipping the Parquet files the importer would produce was rejected: they would silently go stale whenever the importer, the Parquet layout or `groups::apply` changed, while a CSV is imported by whatever code the running build has. At 500 cases the import is instant.

Everything else about the Sample Project lives in TypeScript, in `src/lib/sample-project/manifest.ts`: its Column Mapping, its Groups (two applied, one left as an unapplied Filter List so the Filters Tour has something to Apply), the comparison the tree opens on, and the attributes the tree tests, which lets the Tree view skip the attribute prompt. The frontend writes every row, as it does for an uploaded Project (ADR 0001). Keeping the manifest in TypeScript means the compiler checks its Filters against the Filter union.

The CSV is generated by `scripts/sample-log.ts` from a fixed seed and committed with it. A test regenerates it and compares the bytes, so the data a Tour names (an activity, a Variant, a count) cannot change without the test failing.

The Sample Project has a fixed id, `uuidv5("prodiff:sample-project")`, so the app can recognize it without a schema change, and creating it again replaces it the way seeding a slug again does. It is created only on request, from the empty state or a card in the Projects grid that is shown while no Sample Project exists. Once created it is an ordinary Project: it can be edited, renamed and deleted.

**Consequence:** changing the story means changing the generator, running `pnpm sample:generate`, and updating any Tour that names what changed.
