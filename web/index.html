Opening ProDiff for the first time

ProDiff is not signed yet, so both systems warn about it once. Updates install from inside the app afterwards.

macOS: open the .dmg and drag ProDiff to Applications. If macOS says the app is damaged or cannot be opened, run this in Terminal, then open it again:
xattr -cr /Applications/ProDiff.app

Windows: if SmartScreen shows "Windows protected your PC", click More info, then Run anyway.
